Tiang & kabel

Tracing = JB dilewati B→POP + core di user + spare (JB di A→B tidak dihitung). Labeling kabel = tracing, deadend = tracing ÷ 3, suspension = labeling − deadend. Jointing = 2 di ODF user + semua core kabel (6/24) di JB tapping dan di tiap JB sambungan haspel. Joint Box baru tidak ditambah kalau B adalah JB existing.
